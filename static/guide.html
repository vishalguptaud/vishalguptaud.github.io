Editing guide

Update a page

  1. Open the content editor and select the section to update.
  2. Edit or add an entry, then select Download updated file.
  3. In the repository, replace the matching file under content/ and commit it to main. For publications, that file is content/publications.json.
  4. Check that the publishing workflow succeeded, then review the live page.

The editor does not publish changes or save them between visits. Download each changed section before closing the tab. Start from a fresh load when editing the live site's latest content.

Update the CV or photos

To keep the CV link unchanged, upload a new version of the same PDF in Google Drive. If the link changes, edit it under Profile and appearance.

For photos, upload a prepared public copy to static/assets/uploads/ and use assets/uploads/filename.jpg in the album entry. Add a caption and an accessible description. Keep private originals outside the repository.
